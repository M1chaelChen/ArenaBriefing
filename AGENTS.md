# Release versioning

The user reset release numbering to 0.1.0 with all existing functionality retained.
For subsequent releases, bump only the patch version by default (0.1.1, 0.1.2, etc.).
Bump the minor version only when the user explicitly requests it. Do not infer a minor bump from feature scope.
Keep ArenaBriefing/ArenaBriefing.toc, AB.pack.version in ArenaBriefing/Data.lua, scripts/package.py, and current version references in documentation aligned.
